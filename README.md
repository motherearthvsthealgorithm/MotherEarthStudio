# 🌎 Mother Earth Studio

> Create calm, documentary-style videos that put nature first.

Mother Earth Studio is a free and open-source desktop application for creating beautiful, nature-focused short videos.

It began as the editing tool for the **Mother Earth vs. The Algorithm** project and is being built in public so anyone can use it, improve it, or learn from it.

## Vision

Technology should help people tell meaningful stories.

Whether you're documenting forests, rivers, wildlife, neighborhoods, or communities, Mother Earth Studio aims to make thoughtful storytelling simple.

## Planned Features

- 🎬 One-click vertical video rendering
- 🌲 Natural documentary color grading
- ✨ Gentle title animations
- 🐢 Slow-motion presets
- 🤖 AI-assisted clip selection
- 🎵 Natural audio preservation
- 📱 Export for TikTok, Instagram, YouTube Shorts, and more

## Status

🚧 Early development.

Built one step at a time in the open.
