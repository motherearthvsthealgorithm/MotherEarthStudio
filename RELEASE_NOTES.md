# Mother Earth Studio v0.11.3 — Adaptive Typography Engine

- Measures each Story Highlight against the 1080×1920 title-safe area.
- Balances text across one or two lines.
- Scales typography gradually instead of using only two fixed sizes.
- Shows Fits, Tight, or Won't Fit status in Story Highlights.
- Blocks unsafe overflow before saving or rendering.
- Uses the same layout decision in preview and final FFmpeg render.
- Preserves Story Highlights JSON as the primary overlay source and SRT as fallback.
