# Upgrade from v0.8

Keep your existing MotherEarthStudio folder as a backup. This release is a separate folder.

You do not need to copy files before testing: use the **Choose** buttons to select media from the old project. To consolidate later, copy the contents of the old Forest, Narration, Music, and Subtitles folders into the matching folders here. Do not copy the old `.venv` or old Python files.
